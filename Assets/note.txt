┌─────────────────────────────────────────────────────────────────────────┐
│ 1. SACCENTITY (Classe de base)                                         │
└─────────────────────────────────────────────────────────────────────────┘

CombatLink est un SDK créé par Snipeslow pour VRChat qui standardise la 
communication de données de combat et de santé entre les mondes et les avatars.
Version: 0.5.7 | Unity: 2022.3 | Requis: UdonSharp

┌─────────────────────────────────────────────────────────────────────────┐
│ OBJECTIF PRINCIPAL                                                      │
└─────────────────────────────────────────────────────────────────────────┘
  • Permettre aux avatars d'afficher des HUD fonctionnels avec les données du monde
  • Standardiser le transfert de données de combat/santé entre monde et avatar
  • Communication bidirectionnelle: Monde → Avatar → HUD

╔═══════════════════════════════════════════════════════════════════════════╗
║                          COMPOSANTS PRINCIPAUX                            ║
╚═══════════════════════════════════════════════════════════════════════════╝

┌─────────────────────────────────────────────────────────────────────────┐
│ 1. COMBATLINKMANAGER (Gestionnaire central)                            │
└─────────────────────────────────────────────────────────────────────────┘
  • Gestionnaire principal du système CombatLink
  • Utilise les propriétés globales de shader VRCShader pour communiquer
  • Système d'activation/désactivation (ActivateOnLoad, Interact)
  • Gère toutes les variables de combat via shader globals
  • Compatible UdonSharp uniquement

┌─────────────────────────────────────────────────────────────────────────┐
│ 2. COMBATLINK_COMBATSYSTEMWRAPPER                                      │
└─────────────────────────────────────────────────────────────────────────┘
  • Wrapper pour le système de combat natif de VRChat
  • Récupère automatiquement les HP via Networking.LocalPlayer.CombatGetCurrentHitpoints()
  • Tracking de la santé max
  • Update automatique en LateUpdate()
  • Reset lors de la désactivation

┌─────────────────────────────────────────────────────────────────────────┐
│ 3. COMBATLINKGRAPHWRAPPER                                               │
└─────────────────────────────────────────────────────────────────────────┘
  • Wrapper pour UdonGraph et CyanTrigger
  • Permet l'utilisation de CombatLink sans UdonSharp
  • Interface manuelle pour toutes les propriétés
  • Permet aux créateurs de mondes d'envoyer des données personnalisées

╔═══════════════════════════════════════════════════════════════════════════╗
║                         CARACTÉRISTIQUES TECHNIQUES                       ║
╚═══════════════════════════════════════════════════════════════════════════╝

COMMUNICATION
  • Utilise VRCShader.SetGlobalFloat() pour envoyer les données aux avatars
  • PropertyToID pour optimiser les accès shader
  • Pas de synchronisation réseau (NoVariableSync)
  • Communication locale uniquement (vers l'avatar du joueur)

COMPATIBILITÉ
  • VRChat uniquement (Udon/UdonSharp requis)
  • Unity 2022.3+
  • PC uniquement (Quest/Android non supporté)
  • Compatible avec Avatar 3.0

STRUCTURE
  • Runtime: Scripts UdonSharp et prefabs
  • Editor: Scripts d'édition pour ajouter à la scène
  • Samples: HUDs d'exemple à utiliser sur les avatars
  • Shaders: Includes partagés (CombatLink_Shared.cginc)

UTILISATION
  • MONDE: Installer le prefab CombatLink dans la scène
  • AVATAR: Ajouter un HUD de la collection Samples
  • PERSONNALISATION: Créer des HUDs personnalisés avec les mêmes shader properties

LIMITATIONS
  • Ne fonctionne PAS en dehors de VRChat
  • Nécessite UdonSharp pour les mondes
  • Non compatible Quest/Android
  • Données locales uniquement (pas de sync entre joueurs)
